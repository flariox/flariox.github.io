Guía de Instalación Base de Arch Linux

Esta es una guía rápida en HTML para realizar una instalación manual y limpia del sistema base de Arch Linux en equipos con arquitectura de 64 bits y UEFI.

Nota importante: Asegúrate de contar con una conexión a internet estable antes de iniciar el proceso.

1. Preparación inicial

Configura la distribución del teclado en español (si aplica) y verifica que el sistema haya arrancado en modo UEFI:

loadkeys es
ls /sys/firmware/efi/efivars

2. Conexión a Internet

Verifica que tienes acceso a la red usando el comando ping:

ping -c 3 archlinux.org

3. Particionado del Disco

Identifica tus unidades de almacenamiento utilizando fdisk -l. Luego usa tu herramienta preferida (como cfdisk) para crear la siguiente estructura sugerida:

  • Partición EFI: Al menos 512 MB (Formato: FAT32)
  • Partición Raíz (/): El resto del espacio disponible (Formato: ext4)

Aplica formato a las particiones recién creadas:

mkfs.fat -F 32 /dev/sdX1
mkfs.ext4 /dev/sdX2

Sustituye sdX por la nomenclatura correspondiente a tu disco.

4. Montaje del Sistema

Monta la partición raíz en el directorio /mnt y la partición EFI en su respectiva ruta interna:

mount /dev/sdX2 /mnt
mount --mkdir /dev/sdX1 /mnt/boot

5. Instalación del Sistema Base

Utiliza el script pacstrap para descargar e instalar los paquetes esenciales, el kernel de Linux y utilidades del sistema:

pacstrap -K /mnt base linux linux-firmware nano grub efibootmgr networkmanager

6. Configuración del Sistema (Chroot)

Genera el archivo de la tabla de sistemas de archivos (fstab) y entra en el nuevo sistema raíz con chroot:

genfstab -U /mnt >> /mnt/etc/fstab
arch-chroot /mnt

7. Zona Horaria y Localización

Configura la hora local y los idiomas editando el archivo de locales:

ln -sf /usr/share/zoneinfo/America/Caracas /etc/localtime
hwclock --systohc
nano /etc/locale.gen

(Descomenta tu idioma, por ejemplo: es_VE.UTF-8 UTF-8, guarda los cambios y ejecuta:)

locale-gen
echo "LANG=es_VE.UTF-8" > /etc/locale.conf

8. Red y Contraseñas

Define el nombre de tu equipo (hostname) y crea la contraseña para el usuario administrador (root):

echo "mi-computadora" > /etc/hostname
passwd

9. Cargador de Arranque (GRUB)

Instala y configura el cargador de arranque GRUB para sistemas UEFI:

grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg

10. Finalización

Habilita el gestor de red, sal del entorno chroot, desmonta las unidades y reinicia tu equipo:

systemctl enable NetworkManager
exit
umount -R /mnt
reboot
